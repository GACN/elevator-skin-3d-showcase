# 中梦电梯皮肤 · 3D 展厅 (Material Design 3 · 活力橙)

1:1 实尺电梯皮肤展示：150+160+150×245cm 轿厢三面 / 90×210cm 中分对开门 / 35×245cm 门侧窄墙，4组×8张皮肤。

- 左/中/右 = 后/侧墙 150/160/150cm
- 内部左边/右边 = 门侧 35cm 窄墙（灰色水滴含按钮面板叠加）
- 内门/外门 = 各自中分裁开，左扇取左半、右扇取右半，开关拼回整张（内/外门图不同）
- 内上/内部门上 = 门头横封（已水平镜像）
- 视图：内部透视（纹理门套） / 外部候梯（纯灰门套 #E0E0E0、无按钮）/ 内外对照（双层门）
- 底面顶面隐藏以避免错位，拖拽/滚轮/双击 + 自动旋转

本地预览：`python3 -m http.server 8812` 打开 `http://127.0.0.1:8812/`，局域网 `http://<ip>:8812/`
